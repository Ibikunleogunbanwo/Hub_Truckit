# Glossary

| Term | Meaning |
|---|---|
| Move request | A customer's request for a move, before a quote is accepted |
| Quote | A service center's price offer for a move request (CAD) |
| Move | A confirmed job: a move request plus an accepted quote |
| Service center | A provider account (driver, mover, or both) that sends quotes |
| Mover | A person on a service center's crew who loads and unloads |
| Driver | A service center that provides a truck and drives it |
| Truck type | Category of vehicle, e.g. Cargo Van, Box Truck, Standard Moving Truck |
| Building access | How movers get in at an address: elevator, stairs, ground floor |
| Province | Canadian province or territory; used to match requests to service centers |
| Contract | `contract/openapi.yaml`, the agreed API between frontend and backend |
| Change request | A GitHub Issue in this hub asking the other side to do something |
